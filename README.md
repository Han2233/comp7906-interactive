# COMP7906 网安互动学习

在线学习：https://han2233.github.io/comp7906-interactive/

2026-10-08 英文练习版：按已提供的 Lecture 1–7 顺序整理 88 个互动单元。每个单元有中文解释、英文术语、用途、计算／操作、通俗类比和可操作演示；每章有小结。

配套资料新增完整 Set 1（8 大题）、Set 2（1）、Set 3（4）、Set 4（5）及期中样卷（2），共 20 道大题、43 个自动判分检查点。论述题提供完整参考解释与自评要点，不对自由文字冒充自动评分。已移除整课自测，改为每章末尾一个独立英文选择题模块：第 1–4、6–7 章各 6 题，第 5 章 8 题，共 44 题，支持单章判分、逐题解析和错题重做。术语表有 188 项。课程正文保留中文；原题题干、选项、判分反馈、完整答案、自评要点，以及章节内选择／归类／排序／填空练习均使用英文。

新增 3 套英文期中模拟卷（A/B/C），每套 60 分钟、20 分：Q1 分为 4+4+6 分，Q2 为 6 分。参照配套期中样卷和练习技能，替换情境、数值并增加条件分析。包括手机控制成本相等、资本控制年化、云服务残余风险，以及不同 Bézout 系数和不可逆密文的 RSA 分支。另有 6 道英文变式题，覆盖时间戳、多项式合谋、Hill 已知明文、Feistel、CTR 字段篡改和协议会话绑定。它们是原创练习，不是历年真题或考试预测。

模拟卷可选择、重置并计时。限时尝试隐藏答案并禁止检查，结束或时间到后恢复查看。检查点自动判分；论述题以分值明确的评分点自评，合计显示 /20，不把检查点分数冒充整卷论述评分。切换或重置清空当前答案，作答和计时不跨刷新保存。

新增包括欧几里得回代、RSA 不互质明文证明、循环群／整环／零因子、GF(2) 多项式计算、真实 DES 子密钥、一般段长 CFB、AES-128/192/256 完整加解密、S-AES 逆流程、RC4 全部 KSA 交换、RSA 盲化与平滑数、ECC 点计数、遗漏的密钥分发和 Kerberos 教学消息。

资料导读解释 14 份配套 PDF 的用途，并索引三份手写笔记的 18 页和 13 份历年试卷。历年卷是题型导读，未全部逐题作答。大纲里的量子／后量子密码、完整访问控制模型、Web／安全开发和安全分析后续课件当前未提供，明确标为待补；不能把现有网页称为全学期全部内容。

网页只发布衍生讲解，不上传原始课程／试卷 PDF。历史算法、课堂短参数、简化密码和教学攻击用于理解；与真实部署方案的区别在对应单元说明。

## 使用

直接打开 `dist/index.html` 即可离线学习；在线页面也有“下载离线版”。手机和电脑均可使用。所有计算和练习在当前设备执行，无外部脚本、字体、登录或在线服务依赖。阅读进度保存于当前浏览器。

## 构建与验证

- `python3 build.py`：生成根目录与 dist 中完全一致的独立 HTML。
- `node verify.cjs`：标准向量、300 次 AES 三长度加解密对照、200 次 S-AES、800 次分段 CFB、200 次 Feistel 回验，以及 DES、RC4、SHA-256、GF、Hill、EC、全英文题库、模拟卷评分点及新题答案检查。

前一版曾通过浏览器验证 AES 参数切换、原题判分／重置、时间戳修改检测和 390 / 320 像素布局。本次英文更新已通过语法、有效题库全英文、章节数量、评分点总分、新题计算和离线依赖静态检查。浏览器预览访问被自动审批拦截，本次新增交互与排版的实际浏览器复核仍待完成；不能沿用前版验证结论声称新增功能已点击测试。

源文件：`content.js` 与 `enrichment.js` 是课程正文；`algorithms.js` 是纯计算；`demos.js` 与 `advanced-demos.js` 是实验；`practice.js` 是配套题库；`materials.js` 是导读与补充术语；`quiz.js` 是章节自测与术语；`mock-exams.js` 是模拟卷与变式题；`assessment-localization.js` 是章节内英文练习和配套实验界面；`shell.html`、`supplement-shell.html`、`style.css`、`app.js` 负责页面。
