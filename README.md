# COMP7906 网安互动学习

在线学习：https://han2233.github.io/comp7906-interactive/

2026-10-07 补充版：按已提供的 Lecture 1–7 顺序整理 88 个互动单元。每个单元有中文解释、英文术语、用途、计算／操作、通俗类比和可操作演示；每章有小结。

配套资料新增完整 Set 1（8 大题）、Set 2（1）、Set 3（4）、Set 4（5）及期中样卷（2），共 20 道大题、43 个自动判分检查点。论述题提供完整参考解释与自评要点，不对自由文字冒充自动评分。整课另有 20 道选择题、解析和错题重做。术语表有 188 项。

新增包括欧几里得回代、RSA 不互质明文证明、循环群／整环／零因子、GF(2) 多项式计算、真实 DES 子密钥、一般段长 CFB、AES-128/192/256 完整加解密、S-AES 逆流程、RC4 全部 KSA 交换、RSA 盲化与平滑数、ECC 点计数、遗漏的密钥分发和 Kerberos 教学消息。

资料导读解释 14 份配套 PDF 的用途，并索引三份手写笔记的 18 页和 13 份历年试卷。历年卷是题型导读，未全部逐题作答。大纲里的量子／后量子密码、完整访问控制模型、Web／安全开发和安全分析后续课件当前未提供，明确标为待补；不能把现有网页称为全学期全部内容。

网页只发布衍生讲解，不上传原始课程／试卷 PDF。历史算法、课堂短参数、简化密码和教学攻击用于理解；与真实部署方案的区别在对应单元说明。

## 使用

直接打开 `dist/index.html` 即可离线学习；在线页面也有“下载离线版”。手机和电脑均可使用。所有计算和练习在当前设备执行，无外部脚本、字体、登录或在线服务依赖。阅读进度保存于当前浏览器。

## 构建与验证

- `python3 build.py`：生成根目录与 dist 中完全一致的独立 HTML。
- `node verify.cjs`：标准向量、300 次 AES 三长度加解密对照、200 次 S-AES、800 次分段 CFB、200 次 Feistel 回验，以及 DES、RC4、SHA-256、GF、Hill、EC 和内容入口检查。

本版还通过浏览器验证 AES 参数切换、原题判分／重置、时间戳修改检测、资料筛选／跳转、自测判分与错题重做，检查 390 / 320 像素手机宽度。离线包已静态核对无外部运行依赖；预览工具不允许 file: 协议，未使用它直接打开本地文件。

源文件：`content.js` 与 `enrichment.js` 是课程正文；`algorithms.js` 是纯计算；`demos.js` 与 `advanced-demos.js` 是实验；`practice.js` 是配套题库；`materials.js` 是导读与补充术语；`quiz.js` 是自测与术语；`shell.html`、`supplement-shell.html`、`style.css`、`app.js` 负责页面。

GitHub Pages 从 main 分支根目录部署。
